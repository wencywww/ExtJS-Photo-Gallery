1. Desktop application

The desktop application organizes your photos and videos in a tree by Year → Month → Day, based on the date each file was taken (read from EXIF data when available). The gallery view on the right shows the photos and videos for the day(s) currently selected in the tree.

Navigation tree

  • The tree root (ALL) represents the whole collection.
  • Double-click a Year or Month node to expand / collapse it.
  • Single click on a collapsed Year/Month node does nothing (use double-click to expand it first).
  • Single click on an already expanded Year/Month node loads all the photos from every visible Day node underneath it.
  • Single click on a Day node loads only the photos for that day. Day nodes also show the number of files they contain.
  • Tree nodes are loaded on demand ("lazy loading") by default for faster startup with very large collections. This can be turned off from the Settings menu.

Photo gallery

  • Photos and videos are displayed as thumbnails in a grid.
  • Use the sort buttons (▲ / ▼) to switch between oldest-first and newest-first ordering.
  • Enable Paginate gallery in Settings to split large result sets into pages, with a page-size field and navigation controls at the bottom.
  • If Indicate GPS location is enabled, thumbnails that contain GPS coordinates show a small location icon.
  • Video thumbnails can optionally auto-play (Autoplay video thumbs in Settings).

Filters and search

  • Show Photos / Show Videos toggles in Settings control which file types appear in the gallery and in the day-node file counts.
  • The search icon in the tree toolbar opens a filename filter field. Type part of a filename to show only matching files.
  • Prefix the search text with ! to show files whose name does not match (inverse match), e.g. !IMG.
  • While filtering, a counter next to the field shows how many files match the current filter.
  • Press Esc in the filter field to clear the text and hide the filter field again.

Slideshow, EXIF and GPS data

  • Click any thumbnail to open the full-size slideshow (lightbox) with navigation arrows and keyboard support.
  • If Show EXIF data is enabled, two small icons appear at the bottom of the slideshow:
    • opens a panel with the photo's EXIF metadata (camera, exposure, date/time, etc.).
    • opens a map panel (Google Maps or OpenStreetMap, depending on configuration) showing where the photo was taken, if GPS data is present.

Photo actions (rotate, delete, date, GPS)

Select one or more photos in the gallery (click to select, Ctrl/Shift-click to multi-select), then right-click (or use the toolbar) to access:

  • Rotation — rotate the selected files by 90°, -90° or 180°.
  • Erase selected... — permanently deletes the selected files (and their thumbnails) after confirmation.
  • Change date... — opens a dialog to set a new date for the selected files; this also moves them to the corresponding Year/Month/Day folder and updates the EXIF date in the file.
  • GPS data... — opens the GPS Location Editor:
    • Drag the marker on the map (Google Maps or OpenStreetMap, depending on configuration), or type latitude/longitude/altitude directly.
    • Check Use elevation API to fetch the altitude automatically for the chosen coordinates.
    • Check Preserve existing GPS data in files to skip files that already contain GPS information (uncheck to force-overwrite all selected files).
    • Use Saved Locations to store frequently-used places (name + coordinates + zoom level) and quickly re-apply them later. New/Edit/Delete buttons manage the list.
    • Click Write GPS to save the coordinates into the selected files' EXIF data.

Uploading files

  • Click File Uploader... in the left panel to open the upload window.
  • Drag and drop photos/videos onto the drop area, or click it to choose files from your device.
  • Click Start upload to upload the queued files.
  • After uploading, you will be asked whether to process the files immediately (read EXIF data, generate thumbnails, sort into the Year/Month/Day tree) or do it later via the Process Files button / the play button described below.

Settings menu

Click the gear icon in the tree toolbar to open the settings menu:

OptionDescription
Show EXIF dataShows/hides the EXIF and GPS info icons in the slideshow.
Indicate GPS location presence in thumbsShows a small marker icon on thumbnails that have GPS data.
Show Photos / Show VideosFilters the gallery and file counts by media type.
Autoplay video thumbsAutomatically plays video thumbnails on hover/visibility.
Paginate gallerySplits the gallery into pages instead of one long list.
Lazy tree loadingLoads tree nodes on demand instead of building the whole tree at once. Recommended for large collections.
Use SQLite index (faster browsing)Uses a local SQLite database to speed up tree/gallery loading and the filename filter, instead of scanning the filesystem each time.
Rebuild indexRebuilds the SQLite index from the files on disk. Useful after manual file changes outside the app, or after enabling the index for the first time. Shows progress while running.

All of these preferences are remembered between sessions (stored in your browser).

About the SQLite index: the index is just a local cache file (galleryIndex.sqlite in your photos folder) that speeds up browsing — it does not store your photos or videos. It is safe to delete this file (and its companion -wal/-shm files, if present) if you ever suspect it is out of date or corrupted. The app will simply rebuild it from the files on disk the next time Rebuild index is run, or fall back to scanning the filesystem directly while the index is missing.

Indexer button and disk status

  • The play button () in the left panel checks the uploads folder for new files and processes them (EXIF reading, thumbnail generation, sorting into the tree). A badge shows how many files are pending.
  • The status bar at the bottom of the tree shows the total number of files, the total size of your collection, and the free/total disk space on the server.

2. Mobile application

The mobile app provides a touch-friendly, full-screen experience for browsing your gallery on phones and tablets, with the same underlying data as the desktop app.

Home screen and navigation

  • The home screen shows year cards. Tap a year to drill into its months, then a month to drill into its days, then a day to view its photos.
  • The breadcrumb at the top shows your current location; tap any part of it to jump back to that level.
  • A back-to-cards button next to the breadcrumb returns you to the drill-down cards from a photo list.
  • On phones, the navigation tree opens as a drawer (swipe or use the menu button); on tablets it is shown as a persistent sidebar.
  • In the navigation tree, tap the chevron to expand/collapse a node, and tap the label to load the photos for that node.
  • The Android back button is supported throughout the app: it closes open dialogs/sheets first, then steps back through navigation levels and pagination before exiting.

Photo grid and slideshow

  • Photos and videos are shown in a responsive grid (2 columns on phones, 3-4 on larger screens).
  • Tap a thumbnail to open the full-screen slideshow (lightbox) with swipe navigation.
  • A small marker icon indicates photos that contain GPS data, if enabled in Settings.

Selection mode and actions

  • Long-press a photo to enter selection mode, then tap additional photos to add them to the selection.
  • With one or more photos selected, use the action sheet to:
    • Rotate the selected photos (90°, -90°, 180°).
    • Delete the selected photos/videos.
    • Change the date of the selected files (also moves them in the Year/Month/Day tree).
    • Edit GPS data using the GPS editor and map, including saved locations — same capabilities as on desktop.

Uploading files

  • Tap the floating camera button to open the upload panel.
  • Select photos/videos from your device and upload them.
  • A badge on the upload button shows the number of files pending processing.

Settings

Open Settings from the menu to access:

  • Sort order — newest first or oldest first.
  • Display — Show Photos / Show Videos / Show EXIF data / Indicate GPS location / Autoplay video thumbs.
  • Navigation — Paginate gallery, and toggle/rebuild the SQLite index for faster browsing (same as the desktop option).
  • Appearance — Dark mode.
  • Logout, and the current app version.

Pagination and swipe

  • When Paginate gallery is enabled, a pagination bar appears at the bottom of the photo grid.
  • Swipe left/right on the photo grid to move to the next/previous page.

3. Installation / Docker

The gallery is distributed as a ready-to-run Docker image (wencywwww/extjs-photo-gallery). No database is required — all data is stored as files on disk, optionally with a local SQLite index for faster browsing.

Quick start

  1. Create a folder for your data and a configuration file, for example: 
    mkdir ~/ext-gallery
mkdir ~/ext-gallery/gallery_data
chmod -R 777 ~/ext-gallery/gallery_data
  2. Create ~/ext-gallery/gallery-config.php with your timezone, login credentials and map provider settings: 
    <?php
ini_set('date.timezone', 'Europe/Sofia');

$glob['usr'] = "admin";
$glob['pass'] = "admin";

$glob['mapsProvider'] = "OSM"; // "OSM" (OpenStreetMap, no API key needed) or "GM" (Google Maps)
$glob['gmapsApiKey'] = "place-your-own-api-key-here"; // only needed when mapsProvider is "GM"
  3. Start the container, either directly: 
    docker run -d \
  --name gallery \
  -p 8080:80 \
  -v ~/ext-gallery/gallery-config.php:/var/www/html/inc/globals/gallery-config.php \
  -v ~/ext-gallery/gallery_data:/var/www/html/data/photos \
  wencywwww/extjs-photo-gallery
    ...or with Docker Compose (~/ext-gallery/docker-compose.yml): 
    services:
  gallery:
    image: wencywwww/extjs-photo-gallery
    container_name: gallery
    ports:
      - "8080:80"
    volumes:
      - ./gallery-config.php:/var/www/html/inc/globals/gallery-config.php:ro
      - ./gallery_data:/var/www/html/data/photos
    restart: unless-stopped
    then run docker compose up -d.
  4. Open http://localhost:8080 (or your Docker host's address) in a browser, and log in with the username/password set in gallery-config.php.

Important notes

  • The timezone in gallery-config.php is important — it determines how photo dates are interpreted and how files are organized into the Year/Month/Day tree.
  • The gallery_data directory must be writable by the container (permissions 777 or equivalent).
  • The map provider used for the GPS map features (slideshow location panel, GPS editor, saved locations) is controlled by $glob['mapsProvider']: set it to "OSM" to use OpenStreetMap/Leaflet (no API key required), or "GM" to use Google Maps (requires a valid gmapsApiKey). If mapsProvider is set to "GM" but no valid API key is configured, or if mapsProvider is missing/invalid, the gallery automatically falls back to OpenStreetMap.
  • On the login screen you can switch the language (English / Bulgarian) and the visual theme; these choices are remembered for future visits.
  • For very large collections, enable the SQLite index from the Settings menu and run Rebuild index once to speed up browsing.

Updating to a new version

Your photos, configuration and the SQLite index all live in the mounted gallery_data folder and the gallery-config.php file outside the container, so updating the image does not affect your data.

  1. Pull the new image: 
    docker pull wencywwww/extjs-photo-gallery
  2. Recreate the container with the new image:
    • With docker run: stop and remove the old container (docker stop gallery && docker rm gallery), then run the same docker run command shown above again — it will use the freshly pulled image.
    • With Docker Compose: simply run docker compose pull followed by docker compose up -d — it will recreate the container with the new image automatically.
  3. Open the gallery in your browser. Your photos, settings and saved locations remain unchanged.

If something looks off after an update (e.g. file counts seem out of date), it is safe to rebuild the SQLite index from the Settings menu — see the note in the Desktop section above.
